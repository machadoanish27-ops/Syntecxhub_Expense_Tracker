# Syntecxhub Expense Tracker

A responsive expense tracking application built with React and Vite as part of the Syntecxhub Web Development Internship.

## Features

- Add expenses
- Edit expenses
- Delete expenses
- Search expenses
- Filter by category
- Track total expenses
- Track today's spending
- Transaction count
- Category-wise spending breakdown
- Spending insights
- Mock REST API using JSON Server
- Responsive UI
- Form validation
- Loading and error handling

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Axios
- JSON Server

## React Concepts Used

This project demonstrates:

- `useState`
- `useEffect`
- `useRef`
- `useMemo`
- `useCallback`
